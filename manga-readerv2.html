How to use the reader
Fast setup and easy navigation

Fastest way to read

Paste a WeebCentral chapter or series link into Open from WeebCentral, then tap Open / Search. A series link opens its newest chapter; a chapter link opens that exact chapter.

Pages appear first. The Chapters picker fills in a moment later, once the complete list has loaded.

No link yet? Type the series title in the same box. Results update as you type, and the closest match is highlighted at the top; pick a cover to open that series.

After a series opens, use the Chapters picker to jump to any chapter. Refresh re-fetches the complete chapter list.

Using a different image host? Open Source pattern & scan settings and fill in the URL fields.

Fast navigation

Previous Chapter opens the older chapter and replaces the view. Next Chapter opens the newer chapter and appends it. Enter a number in Auto next and tap Load Next to add several chapters automatically.

Every button & box

Open from WeebCentral

Paste a chapter link, a series link, or type a title. WeebCentral links fill the source pattern and load exact page images automatically.

Open / Search

Opens a pasted link. If you typed a title instead, it searches WeebCentral and shows matching series below the box.

Search results

Results update as you type and include every match WeebCentral returns, with the closest title highlighted first. Tap a cover or title to open that series at its newest chapter.

Chapters picker

Lists every chapter in the open series. Filter by number, or choose a chapter to load it. Refresh reloads the complete list from WeebCentral.

Source pattern & scan settings

Expand this only for custom image hosts or manual URL patterns. Link loading fills these fields for you.

Group

Selects a saved settings/source group.

Group name

Name used when saving or renaming the current group.

New Group

Creates a blank settings group.

Save Group

Saves the current source, chapter, page, retry, scan and display settings. Renaming moves the group.

Delete Group

Deletes the selected saved group after confirmation.

Export Settings

Downloads your saved groups as a JSON backup file.

Import

Loads a previously exported JSON settings file.

Source URL prefix 1

Primary image source. The reader builds each image URL from this prefix plus the chapter/page pattern. Link loading fills this automatically.

Source URL prefix 2

Backup image source. It is checked when Source 1 fails and is retried if a page later breaks.

Chapter box

Current chapter number/text. Link loading fills this automatically.

Chapter pad

Number of leading zeros used for chapters. Example: 4 makes 12 become 0012.

Separator

Characters between chapter and page, such as a dash.

Page start box

First page number to check.

Page pad

Number of leading zeros used for pages. Example: 3 makes 1 become 001.

Suffix

File ending added to the URL, such as .png or .jpg.

Preview source 1

Shows the URL created from the current chapter/page settings. Copy it or test it directly.

Max pages

Maximum number of pages checked for one chapter.

Stop after missing

Number of consecutive missing pages in a row before the scan stops. A low value stops a blank chapter quickly; a higher value tolerates a few gaps between pages.

Retry times

Extra attempts after a page fails. 0 means no retries.

Retry wait (ms)

Delay between failed attempts. A successful page stops retrying immediately.

Latest scan

Maximum forward chapter range used by Latest Chapter.

Missing chapters

Consecutive missing chapters allowed before the latest scan stops.

Reader width

Maximum manga display width: Small, Normal, Large, or XL.

Image proxy

Auto tries the direct image URL first, then Google's image pipeline (G), then P1 (images.weserv.nl) and P2 (wsrv.nl) — no search is involved, the proxy just fetches the same image. Use “Proxy first” or “Proxy only” on networks that block the image host; “Off” disables it. Offline saves and downloads always keep the original URL.

Load / Filter Pages

Starts a fresh load from the current URL pattern and clears the current page list before scanning.

Latest Chapter

Refreshes the linked series and opens its newest chapter. Without a link, it searches forward using the chapter pattern.

Previous Chapter

Opens the older chapter, resets to page 1, and replaces the pages.

Next Chapter

Opens the newer chapter, resets to page 1, and appends its pages without clearing existing pages.

Auto next

Number of chapters to automatically add.

Load Next

Repeats the Next Chapter action and waits for each chapter to finish before continuing.

Stop

Cancels the active link lookup, scan, or auto-load chain.

Clear

Stops the active loading run and removes all displayed pages.

Hide Panel

Hides the settings menu for clean reading.

Menu tab

Opens the settings menu. On phones it is touch-safe and the menu can scroll.

Page badge

Shows the page code and which source supplied it (S1, S2, or G/P1/P2 for the image proxy).

Click a page

Opens the lightbox. Use Prev/Next, Fit, +/−, Open original, or Download.

Reading HUD

Shows the current chapter, loaded page count and your page position.

Failed page card

Tries the backup source automatically. If every source fails, use Retry.

Previous chapter.

Reload the current chapter from scratch.

Hide the menu or close the guide/lightbox.

About link lookup

WeebCentral blocks direct browser requests, so link and title lookup is read through r.jina.ai. Only the page you request is sent; your saved settings stay in this browser. If lookup is slow or unavailable, paste a chapter link again or use the manual source pattern.
